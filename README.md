# NodeSeek 一级及以下标记与屏蔽

一个轻量的 NodeSeek 油猴脚本：**先看清哪些内容来自 Lv.0 / Lv.1，再自行决定是否屏蔽。**

默认只标记，不隐藏内容。帖子和评论使用两个独立开关，关闭后立即恢复。

**[一键安装到 Tampermonkey](https://github.com/V3ynix/nodeseek-level1/raw/refs/heads/main/nodeseek-level1.user.js)** · [查看源码](./nodeseek-level1.user.js) · [反馈问题](https://github.com/V3ynix/nodeseek-level1/issues) · [MIT 许可](./LICENSE)

> 私密仓库访问说明：如果仓库处于 Private 状态，只有获得授权的 GitHub 账号能查看和安装；请先在浏览器登录该账号。部分脚本管理器不能携带 GitHub 私密仓库登录凭据，此时使用下方的手动安装方式。安装链接不包含 Token，也不会绕过仓库访问权限。仓库公开后，无需 GitHub 登录即可获取脚本。

## 功能

| 功能 | 行为 |
| --- | --- |
| 一级及以下标记 | 覆盖 Lv.0 和 Lv.1；徽标显示实际等级，不把 Lv.0 标成 Lv.1 |
| 帖子标记 | 列表标题旁显示 `Lv.0 发帖` 或 `Lv.1 发帖`；打开主题后主楼作者旁也会标记 |
| 评论标记 | 回复作者旁显示 `Lv.0` 或 `Lv.1` |
| 独立屏蔽 | 「屏蔽一级及以下帖子」与「屏蔽一级及以下评论」互不影响 |
| 立即恢复 | 关闭对应开关即可重新显示内容，不需要刷新 |
| 记住设置 | 使用当前 NodeSeek 站点的本地存储保存开关，同源标签页同步设置 |
| 动态内容 | 监听页面新增内容、作者链接变更和节点复用，重新判断对应作者 |
| 查询失败保护 | 显示「等级未知」，保留内容，不把失败当作低等级 |
| 页面统计 | 面板显示当前页面的低等级帖子、评论、屏蔽数量及查询状态 |

## 安装

### 1. 安装 Tampermonkey

从 [Tampermonkey 官网](https://www.tampermonkey.net/) 选择对应浏览器的官方扩展。

本项目面向 Chrome / Chromium 与 Tampermonkey。新版 Chrome 如果提示脚本不能执行，请按扩展提示在扩展详情中允许用户脚本；不同浏览器版本可能还要求打开扩展开发者模式。

### 2. 一键添加脚本

1. 确认 Tampermonkey 已安装并启用。
2. 点击 **[一键安装](https://github.com/V3ynix/nodeseek-level1/raw/refs/heads/main/nodeseek-level1.user.js)**。
3. 在 Tampermonkey 的安装确认页检查名称、版本与匹配域名，然后点击「安装」。
4. 打开或刷新 [NodeSeek](https://www.nodeseek.com/)，右下角出现「Lv.0 / Lv.1 助手」。

“一键安装”指直接进入脚本管理器的安装流程，仍需要你确认安装；不会静默安装浏览器扩展或绕过浏览器授权。

### 手动安装

如果链接打开成源码、GitHub 登录页或 404：

1. 确认当前 GitHub 账号有仓库访问权限。
2. 打开 [脚本源码](./nodeseek-level1.user.js)，复制完整内容，包含开头的 `// ==UserScript==` 元数据。
3. 点击 Tampermonkey 图标 →「添加新脚本」。
4. 用复制的内容替换默认模板，按 `Ctrl+S` 保存。
5. 刷新 NodeSeek。

升级已有安装时，优先编辑原脚本或确认覆盖安装，避免同时启用多个副本。仓库内的本地文件名为 `nodeseek-level1.user.js`。

## 使用

右下角面板可以点击标题折叠或展开。

| 控件 | 默认状态 | 开启后的作用 |
| --- | --- | --- |
| 屏蔽一级及以下帖子 | 关闭 | 隐藏列表中 Lv.0 / Lv.1 作者发布的主题；在主题详情页隐藏对应主楼内容，但不连带隐藏其他人的评论 |
| 屏蔽一级及以下评论 | 关闭 | 隐藏 Lv.0 / Lv.1 作者的回复，不改变主楼是否显示 |

- 两个开关都关闭时，只标记、不屏蔽。
- 可以只开其中一个，也可以同时开启。
- 关闭开关后，脚本隐藏的内容立即恢复；NodeSeek 自己的拉黑、权限限制或已删除内容不会因此恢复。
- 脚本只修改你浏览器里的显示，不会提交站内拉黑操作，不会删除帖子、评论，也不会改变作者账号。
- 初次进入页面，作者等级需要逐步查询；识别完成后才标记或按开关隐藏，可能短暂看到未过滤内容。
- 面板统计的是已识别的页面节点，不是全站账号数量；轮播等重复展示节点可能分别计数。

## 等级如何判断

只使用 NodeSeek 自身的账号信息接口：

```text
GET /api/account/getInfo/{UID}
```

从成功响应中读取 `detail.rank`，并核对响应中的 `detail.member_id` 与被查询 UID 一致。

| 接口结果 | 标记 | 是否受屏蔽开关控制 |
| --- | --- | --- |
| 有效整数等级 `0` | `Lv.0` / `Lv.0 发帖` | 是 |
| 有效整数等级 `1` | `Lv.1` / `Lv.1 发帖` | 是 |
| 有效整数等级 `2` 或更高 | 不添加低等级徽标 | 否 |
| 请求失败、无权限、响应格式异常或等级无效 | `等级未知` | 否，保留内容 |

不会根据 UID 大小、注册时间、昵称或最后回复人的等级猜测发帖人等级。列表取主题作者，评论取该条回复作者。

### 请求与缓存

- 同一个 UID 在当前页面内复用同一次查询结果，不重复发起并发查询。
- 最多并行查询两个 UID，每次查询结束后留出 250 毫秒再释放该查询槽位。
- 单次请求超时为 10 秒；失败不自动重试，刷新页面可重新查询。
- 成功结果在当前标签页的 `sessionStorage` 中缓存 30 分钟，持久化缓存最多保留 500 条。
- 缓存命中时可能显示最近一次查询到的等级，账号刚升级时不会立刻反映；同一页面已完成的判断也不会定时重新查询。
- 想立即重新查询，可在该标签页开发者工具 Console 中执行下方命令，然后刷新：

```js
sessionStorage.removeItem('nsl1:ranks:v1');
location.reload();
```

不要高频刷新或批量打开大量页面，以免增加 NodeSeek 的接口负担。站点限流或验证失败时，脚本不会尝试绕过限制。

## 隐私与权限

脚本声明 `@grant none`，没有第三方运行依赖，不需要构建或安装额外库。

- 脚本运行时，只向当前 NodeSeek 域名请求账号等级；同源请求会使用浏览器现有的 NodeSeek 登录会话。
- 不读取或上传 Cookie，不收集浏览记录、帖子正文、评论正文或个人资料；不会把 NodeSeek 数据发送到 GitHub 或其他第三方。
- 脚本管理器在安装、检查更新时可能访问 GitHub，这是安装与更新流程，不是等级查询。
- `localStorage` 的 `nsl1:settings:v1` 只保存帖子、评论两个开关。
- `sessionStorage` 的 `nsl1:ranks:v1` 保存 UID、等级和查询时间，用于当前标签页缓存。
- 存储属于当前 NodeSeek 域名，不是秘密保险箱；站点同源 JavaScript 可以访问这些数据。
- `www.nodeseek.com` 与 `nodeseek.com` 属于不同源，设置和缓存不会跨这两个域名同步。
- 等级查询失败时，浏览器 Console 会输出相应 UID 和错误原因，便于排查。

## 更新与卸载

### 更新

脚本元数据包含本仓库的 `@downloadURL` 和 `@updateURL`。Tampermonkey 可按自己的设置检查更新，也可以手动点击安装链接并确认覆盖。

私密仓库期间，自动更新可能因 GitHub 登录权限失败；此时从仓库复制新版代码，替换原脚本并保存。不要把 GitHub Token 写入脚本、README 或安装链接。

### 卸载

在 Tampermonkey 管理面板禁用或删除脚本，随后刷新 NodeSeek 即可移除页面标记和面板。

如需同时清除本脚本在当前域名、当前标签页留下的数据，可在 NodeSeek 开发者工具 Console 中执行：

```js
localStorage.removeItem('nsl1:settings:v1');
sessionStorage.removeItem('nsl1:ranks:v1');
```

如果脚本仍在运行，请先禁用再刷新，避免缓存或设置再次被写入。其他标签页有各自的会话缓存。

## 常见问题

### 点击安装后没有进入 Tampermonkey

确认扩展已启用、允许用户脚本执行，并允许它访问 NodeSeek。私密仓库还需要 GitHub 访问权限。浏览器或脚本管理器未接管链接时，使用手动安装，不要反复点击。

### 看不到面板

确认当前地址匹配下列 HTTPS 域名、脚本已启用且没有被扩展限制，然后刷新页面：

```text
https://www.nodeseek.com/*
https://nodeseek.com/*
```

如果存在旧版临时注入或重复安装，先只保留一个启用的脚本，再刷新。

### 为什么一些内容仍然显示

可能尚在查询、等级高于一级，或接口无法确认等级。脚本只屏蔽已经确认属于 Lv.0 / Lv.1 的内容，不会因为接口错误而隐藏全部内容。查看面板的「查询中」和「等级未知」提示。

### 为什么开启帖子屏蔽后仍能看到评论

这是独立开关的设计。帖子开关只隐藏列表主题或详情主楼；回复是否隐藏由评论开关和回复作者等级决定。

### 缓存导致等级没更新怎么办

按照「请求与缓存」章节清除本标签页的等级缓存并刷新。只刷新页面可能继续命中尚未过期的会话缓存。

### 手机或其他脚本管理器能用吗

脚本使用标准 DOM API，但本项目没有完成手机端或所有脚本管理器的适配验证；以对应浏览器的实际表现为准。

### NodeSeek 改版后失效怎么办

脚本依赖当前的列表、主楼、评论作者 DOM 结构，以及站内账号等级接口。它们不是本项目控制的稳定 API，改版可能需要更新脚本。请通过 [Issues](https://github.com/V3ynix/nodeseek-level1/issues) 提供脱敏复现信息。

## 开发与验证

仓库无需构建，主文件就是可安装的油猴脚本。

```text
nodeseek-level1.user.js  脚本源码与安装文件
README.md               使用、安装与开发说明
LICENSE                 MIT 许可
```

修改后可以先运行语法检查：

```sh
node --check nodeseek-level1.user.js
```

随后用浏览器验证实际行为，不能只依赖语法检查：

- Lv.0、Lv.1：徽标显示真实等级，默认不隐藏。
- Lv.2 及以上：不添加低等级徽标，两个开关都不应隐藏它们。
- 未知或失败响应：显示「等级未知」，即使两个开关都开启也保留内容。
- 分别开启帖子、评论开关，检查互不影响；关闭后立即恢复。
- 刷新后开关状态保留；动态插入内容、作者链接变更和复用节点后重新判断。
- 检查等级缓存、查询去重和并发上限；不要使用真实站点进行高频压测。

此前浏览器验证覆盖真实 NodeSeek 页面中的 Lv.1 主题、回复与独立开关；Lv.0 / Lv.1 / Lv.2 / 未知等级的边界使用受控模拟响应验证。模拟响应不是对某个真实账号等级的声明。

欢迎提交问题和改进建议。复现时请注明浏览器、Tampermonkey 版本、脚本版本和页面类型；不要提交 Cookie、Token、未脱敏的账号信息或私密帖子正文。
