# NodeSeek 一级及以下标记与屏蔽

标记 NodeSeek 上 **Lv.0 / Lv.1** 账号发布的帖子和评论，想屏蔽时再开启开关。默认只标记，不隐藏。

**[一键安装油猴脚本](https://github.com/V3ynix/nodeseek-level1/raw/refs/heads/main/nodeseek-level1.user.js)** · [查看源码](./nodeseek-level1.user.js) · [反馈问题](https://github.com/V3ynix/nodeseek-level1/issues)

## 安装

1. 安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击上方「一键安装油猴脚本」，在油猴确认页点击安装。
3. 刷新 [NodeSeek](https://www.nodeseek.com/)，右下角会出现「Lv.0 / Lv.1 助手」。

> 如果链接只显示源码：复制完整内容 → 油猴「添加新脚本」→ 替换默认模板 → `Ctrl+S` 保存。没有面板时，检查扩展是否允许执行用户脚本，并避免重复启用多个副本。

## 使用

帖子标题旁显示 `Lv.0 发帖` / `Lv.1 发帖`，评论作者旁显示 `Lv.0` / `Lv.1`。

| 开关 | 开启后的效果 |
| --- | --- |
| 屏蔽一级及以下帖子 | 隐藏列表主题和详情主楼，不连带隐藏其他人的评论 |
| 屏蔽一级及以下评论 | 隐藏对应作者的回复，不影响主楼 |

两个开关**默认关闭、互不影响**；关闭后立即恢复显示，设置自动保存。支持动态加载内容，点击面板标题可折叠。

## 说明

- **不猜等级**：使用 NodeSeek 自身的等级接口，不按 UID 判断；查询失败显示「等级未知」，保留内容。
- **有查询延迟**：识别完成后才标记或屏蔽；成功结果在当前标签页缓存 30 分钟，等级变化可能不会立即反映。
- **只改本地显示**：不操作站内拉黑列表，不上传数据到第三方；开关和等级缓存保存在浏览器中。
- **适用环境**：面向 Chrome / Chromium + Tampermonkey；其他浏览器、手机端未完整验证。站点改版可能需要更新脚本。

更新可在油猴中检查更新；禁用或删除脚本后刷新页面即可停止生效。
